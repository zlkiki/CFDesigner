Section Wizard - Page 1 of 2

This window is displayed by selecting New Section from the File menu. The Section Wizard is used to easily create the geometry for many common shapes. Once you finish the Wizard, you have full editing capabilities for the section.

The first page of the Section Wizard is used to select the type of section you want to create. After you select the shape, press the Next button to proceed to the next page (see Page 2).

If the shape isn't represented, you may define any shape by choosing `Custom', and then pressing the Finished button. This will create a section with no geometry, from which you may start building the shape you need.
