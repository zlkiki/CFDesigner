Windows Menu

The following commands are available on the Windows menu:

CascadeArranges all the CFS windows starting in the upper left corner working down and to the right.
Tile HorizontalArranges all the CFS windows in horizontal rows so they are all visible and equal in size.
Tile VerticalArranges all the CFS windows in vertical columns so they are all visible and equal in size.
Arrange IconsOrganizes minimized windows neatly at the bottom of the CFS window.
Close AllCloses all windows, except for the main CFS window.
Window ListAll CFS windows are listed here. To switch to any of these windows, simply select it from the list.
