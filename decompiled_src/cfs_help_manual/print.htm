Print

This window is displayed by selecting Print from the File menu. It is not available if there are no windows currently open. A list of all available items to print are displayed, based on the currently open files and generated reports. You may select any or all of the outputs in the list. Entries that share the same heading information are positioned adjacent to each other in this list. If you select multiple entries that share the same heading information, these printouts may combine to conserve paper.

Heading ButtonThis button displays the Heading Tab of the Options window. This allows you to make changes to heading information prior to printing. Note however that you cannot change the user name at this point since it wouldn’t affect headings for current reports. It only affects headings for subsequently edited sections or analyses.
