Options - Heading Tab

This window is displayed by selecting Options from the Tools menu. This information is included in the heading of all printouts.

User NameThe user name to be assigned to any section or analysis that is edited. The heading of all printouts shows the user name of the person who last edited the file, which might be this user name or someone else.
CompanyThe company or organization to include in the heading of all printouts.
AddressTwo lines of company address to include in the heading of all printouts.
E-mailThe e-mail address to include in the heading of all printouts.
PhoneThe phone number to include in the heading of all printouts.
FaxThe fax number to include in the heading of all printouts.
