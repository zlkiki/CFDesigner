View Menu

This menu controls visibility of various windows and options.

ToolbarDisplays and hides the CFS toolbar.
Input Windows on TopIf this option is unchecked, the input windows (when open) will be displayed on top of the main application window when active, and behind the main application window when not active. In either case, the input windows may be moved outside the boundaries of the main application window. They may also be closed and re-opened at any time.
Section InputsDisplays the Section Inputs window.
Analysis InputsDisplays the Analysis Input window.
Render MembersOption to illustrate member shapes in the Analysis Window.
X-Y AxesOption to display the X-Y axes in the Section Window and Analysis Window.
