## 1. 구현 목표

1. **KaTeX 수식 렌더링 누락 수정**:
   - 유효단면 모달(`effectiveModal`) 내 $A_e$, $A_e/A_g$, $I_{xe}$, $\Delta y$, $f$ 기호가 `$A_e$` 등 텍스트로 보이지 않고 KaTeX 라이브러리로 수식 렌더링되도록 처리.
2. **수치해석 계산 및 결과 표시의 모달 내부 완결 (실시간 연산)**:
   - 적용 응력 수준 $f$ 및 휨/압축 재하축 선택 시 150ms 디바운스로 백엔드 `/api/geometry/effective-width`를 호출하여 **유효단면 수치해석창 내부의 결과란($A_e, A_e/A_g, I_{xe}, \Delta y$)에 즉각 실시간 계산되어 표시**.
   - 창을 열고 수치를 변경하는 단계에서는 메인 화면(단면 기하학적 성질란 등)에 바로 적용되지 않고 오직 **해당 수치해석창 내부에서만 독립적으로 실시간 계산/표현**.
3. **계산과 2D 오버레이 기능 명확 분리 및 2D 캔버스 오버레이 버튼 동작**:
   - 기존의 단일 버튼에 묶여있던 계산/오버레이 기능을 명확히 분리: 수치 계산은 창 내부에서 실시간으로 완결되고, 버튼은 **[⚡ 유효단면 2D 캔버스 오버레이]** 전용 버튼으로 동작.
   - **모달 [⚡ 유효단면 2D 캔버스 오버레이] 클릭 시**: 모달이 닫히며 2D 캔버스에 유효단면 형상이 점선(Dashed blue stroke)으로 즉시 오버레이 표현되고, 상단 2D 툴바의 **[👁️ 유효단면]** 버튼이 활성화(Pressed/Active `.active`) 상태로 전환되며, 우측 단면 기하학적 성질란 하단에 비로소 **[유효단면 성질 ($f=...$ MPa)]** 정보 블록이 함께 표기.
   - **툴바 버튼 재클릭 시**: 이미 오버레이된 유효단면 점선이 2D 화면에서 깔끔하게 제거되고 툴바 버튼 눌림 해제 및 우측 단면성질란 유효단면 표기 해제.
4. **우측 패널 단면성질 하단 유효단면 정보 연동 및 단면변경 시 자동 리셋**:
   - 2D 캔버스에서 마법사, DXF 로드, 툴바 변환(회전, 대칭 등) 발생 시 유효단면 오버레이 자동 해제, 툴바 버튼 비활성화, 우측 유효단면 정보 표기 자동 제거.

## 2. 세부 수용 기준 (Acceptance Criteria)

- [ ] **AC 9-2-1**: 유효단면 모달 내 $A_e, I_{xe}, \Delta y$ 등 모든 수식 기호가 KaTeX로 수려하게 렌더링된다.
- [ ] **AC 9-2-2**: 응력 $f$ 값을 입력하거나 모멘트 축을 변경할 때 수치해석창 내부의 결과 수치가 실시간으로 갱신되며, 메인 화면에는 영향 주지 않는다.
- [ ] **AC 9-2-3**: [2D 오버레이] 버튼 클릭 시 모달이 닫히고 2D 캔버스에 점선이 표기되며, 툴바 버튼이 눌러진 상태로 표시되고 우측 패널 하단에 유효단면 정보가 함께 표기된다.
- [ ] **AC 9-2-4**: 툴바 버튼을 다시 누르면 오버레이가 깔끔하게 제거되고 우측 패널의 유효단면 정보도 함께 사라진다.
- [ ] **AC 9-2-5**: 단면 변경 작업 시 기존 유효단면 오버레이와 툴바 활성 상태, 우측 유효단면 정보가 자동으로 리셋된다.
