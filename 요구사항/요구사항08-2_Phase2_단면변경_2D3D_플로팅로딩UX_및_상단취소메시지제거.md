## 1. 구현 목표 (1이슈 단일 집중)

* **이슈 내용**: 
  1. 도구상자(마법사/라이브러리/변환 등)로 단면을 바꿀 때 이전 계산 마커(도심 $C_G, S_C$)가 남아있어 혼란을 줌.
  2. 3D 뷰어에서 단면 변경 연산 중 시각적 피드백이 부족함.
  3. 연산 중복 호출 방지 시 "중간에 계산을 취소하고..." 알림이 상단에 거슬리게 노출됨.
* **목표**:
  - 2D: 단면 선 변경 즉시 이전 $C_G, S_C$ 삭제 $\rightarrow$ "⏳ 단면 성질 계산 중..." 플로팅 $\rightarrow$ 완료 시 신규 $C_G, S_C$ 표시.
  - 3D: 화면 블러/Dim $\rightarrow$ "⏳ 좌굴해석 재계산 중..." 플로팅 $\rightarrow$ 완료 시 신규 3D 형상 렌더링.
  - 상단 "중간에 계산을 취소하고..." 시스템 알림 완전 제거.

---

## 2. 세부 개발 명세

1. **2D 캔버스 로딩 UX (`canvas_2d.js`, `app.js`)**:
   - `clearPropertiesMarkers()`: 새 단면 적용 즉시 호출하여 이전 $C_G, S_C$, 주축선을 즉시 삭제.
   - `showLoadingFloating(message)`: 캔버스 정중앙에 반투명 캡슐 배지(`⏳ 단면 성질 계산 중...`) 렌더링.
   - API 응답 완료 시 신규 속성값 전달 및 `hideLoadingFloating()` 호출.
2. **3D 뷰어 블러 & 로딩 UX (`viewer_3d.js`)**:
   - 단면 변경 트리거 시 3D 컨테이너에 `.canvas-blur-loading` 클래스 부여 (`filter: blur(2px); opacity: 0.6; transition: all 0.2s;`).
   - 중앙에 `[⏳ FSM 좌굴해석 재계산 중...]` 오버레이 배지 표시.
   - FSM 해석 완료 시 블러 해제 및 신규 3D 메쉬 업데이트.
3. **상단 시스템 알림 정리 (`app.js`)**:
   - Debounce나 `AbortController` 취소 발생 시 UI 토스트나 상단 배너에 "중간에 계산을 취소하고..." 메시지를 띄우지 않고 내부 콘솔 로그로만 조용히 처리.
