## 1. 구현 목표

1. **3D 뷰어 좌굴 모드 버튼 Active 상태 유지**:
   - 현재 렌더링 중인 좌굴 모드(로컬 `local`, 디스토셔널 `distortional`, 글로벌 `global`)에 맞춰 상단 버튼이 눌러진 활성 상태(`.active`)로 유지.
2. **도움말 5-2 도해2 기준 3D 탄성 버클링 UI 기능 전수 추가**:
   - **X, Y, Z 3축 좌표계 렌더링**: 3D 뷰어 좌측 하단에 축 방향 Triad 기호(X: 빨강, Y: 초록, Z: 파랑) 렌더링.
   - **Work Ratio & Direct Strength 지표 표기**: 3D 뷰어 상단 정보 오버레이에 반파장($L$), 좌굴계수($\beta$), Work Ratio(내부 변형에너지 비율), 다이렉트 스트렝스 공칭강도($P_n$ 또는 $M_n$) 표기.
   - **스트레스 프로파일(Stress Profile) 표시**: 단면 둘레의 압축/인장 초기 응력 분포 다이어그램 렌더링 토글.
   - **진동 애니메이션 시작/중지(Play/Pause) 버튼**: 좌굴 변형 애니메이션 일시 정지 및 재개 버튼 추가.
   - **인쇄(Print) 및 화면 저장(Export Image) 버튼**: 고해상도 3D 좌굴 화면 PNG 이미지 다운로드 및 인쇄 지원.
3. **도움말 5-2 도해3 기준 2D 단면 변형 모드형상 (Cross-section Mode) 출력**:
   - 2D 캔버스에 선택된 반파장에서의 2D 평면 좌굴 변형 단면(횡변위 및 회전이 반영된 모드 형상) 렌더링 모드 지원.
4. **도움말 5-2 도해4 기준 3D 길이방향 사인파(Longitudinal Sine Wave) 파형 렌더링**:
   - 3D 부재 축방향($Z$)을 따라 $\sin(\pi z / L)$ 파형으로 진폭이 변화하는 3D 입체 좌굴 파형 렌더링 효과 구현.
5. **단면 코너 반경(Corner Radius) 원본 소스 및 2D/3D 일체화 점검**:
   - 원본 C# (`RSG/CFS/Part.cs`, `Section.cs`)의 코너 반경 로직을 전수 점검하여 2D/3D 뷰어 및 엔진에 완전 반영.
