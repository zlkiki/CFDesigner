# 요구사항 12: FSM 버클링 해석 비동기 요청 제어 & 예외 처리 정밀화 (버그 픽스)

## 1. 배경 및 문제 정의 (Issue Summary)

### 1.1 현상
- 웹 UI 상에서 단면을 생성하거나 DXF 업로드, 매개변수 수정 시 간헐적으로 하단 글로벌 상태 표시줄에 `FSM 탄성 버클링 해석 실패` 경고가 노출되는 현상 발생.

### 1.2 원인 분석 (Root Cause Analysis - ⚠️ 분석 내용 의심스러움 / 재검증 필요)
> ⚠️ **주의 (사용자 피드백 반영)**: 
> 현재 작성된 원인 분석(프론트엔드 비동기 AbortController 타이밍 이슈 등)은 겉으로 드러난 현상에 기반한 1차 가설일 뿐이며, **실제 원인인지 여부가 매우 의심스러운 상태**입니다.
> 
> 실패가 발생한 근본 원인이 **단순 비동기 메시지 덮어쓰기 문제인지, 아니면 백엔드 FSM Solver/EigenSolver 수치해석 과정에서 실제로 예외/NaN/발산 오류가 발생하여 실패를 반환한 것인지**를 절대로 덮어버리지 말고, 내일 작업 시 **실제 에러 로그/페이로드 역추적을 통해 근본 원인을 처음부터 다시 정밀 재검증**해야 합니다.

1. **비동기 요청 경합 및 AbortController 오작동 (가설 1)**:
   - `runWizard()`, `updateSectionData()` 호출 시 `runFSM()`과 `runDesignCheck()`가 동시에 비동기로 트리거됨.
   - 단면 변경 시 이전 진행 중이던 FSM 요청을 취소하기 위해 `AbortController.abort()`를 호출하는데, 프론트엔드의 `runFSM()` catch 블록에서 `err.name === 'AbortError'` 체크 후 조용히 빠져나가는 과정과 정상 응답의 완료 콜백 간에 타이밍 경합(Race Condition)이 발생했을 가능성.
2. **`!res.ok` 응답 처리 미흡 (가설 2)**:
   - `res.ok`가 `false`일 때 (HTTP 422 또는 500 등) 에러 바디를 파싱하지 않고 단순 `return;` 처리되어, 로딩 상태가 영구 유지되거나 백그라운드에서 상태 메시지 덮어쓰기가 불일치함.
3. **FSM 수치해석 엔진 엣지 케이스 안정성 및 실제 Solver 실패 가능성 (가설 3 - 중점 검토 대상)**:
   - 매우 얇은 단면($t < 0.5\text{ mm}$)이나 특정 반파장 $L$에서 기하 강성행렬 $[K_g]$의 특이성(Singularity)으로 인해 고유치 해가 추출되지 않거나 실제 Solver 크래시/500 에러가 발생했을 가능성.

## 2. 세부 요구사항 및 개선 방안 (Action Items)

### 2.1 프론트엔드 비동기 생명주기 및 상태 관리 정밀화 (`src/web/static/js/app.js`)
1. **FSM Debounce & AbortController 통합**:
   - 단면 기하 데이터 변경 시 불필요한 연속 호출을 방지하고, 최신 요청만 단일 파이프라인으로 처리하도록 디바운스 및 취소 시그널 완벽 동기화.
2. **명확한 에러 메시지 디스플레이**:
   - 서버에서 오류가 발생한 경우 서버의 `detail` 메시지를 명확히 추출하여 상태 바에 표시하고, 단순 취소(`AbortError`)인 경우에는 실패 메시지가 상태 바를 오염시키지 않도록 방어.
3. **로딩 인디케이터 정상 복구**:
   - 해석 실패 또는 중단 시 2D/3D 캔버스의 로딩 인디케이터(`hideLoading()`)가 항상 정상 해제되도록 `finally` 블록 보강.

### 2.2 백엔드 FSM Solver 방어 로직 강화 (`src/solver/signature_curve.py`, `src/api/routes.py`)
1. **고유치 해석 실패 반파장 예외 방어**:
   - 특정 반파장에서 고유치를 찾지 못하더라도 전체 시그니처 커브 계산이 중단(HTTP 500)되지 않고, 인접 파장 값 보간 또는 유효한 고유치만 필터링하여 정상 응답(HTTP 200) 반환하도록 Solver 견고화.
2. **입력 기하 유효성 사전 검증**:
   - 유효하지 않은 요소(길이 0, 두께 0 등)에 대해 FSM 진입 전 조기 경고 반환.
