## 1. 개요 및 목표

* 사용자의 작업 흐름과 현재 데이터 상태를 실시간으로 모니터링하여, 화면 하단에 **"다음 권장 공학 작업"을 스마트하게 제안하는 어시스턴트 바(`#smartActionBar`)**를 구현합니다.
* 사용자가 "이 단계 다음에 무엇을 해야 하지?" 고민할 필요 없이, 상태에 부합하는 원클릭 액션 버튼을 통해 파이프라인을 자연스럽게 완주할 수 있도록 유도합니다.

---

## 2. 세부 개발 항목

### 2.1. 스마트 어시스턴트 바 컴포넌트 마크업 (`index.html`)
* 화면 하단 고정/플로팅 형태의 `#smartActionBar` 컨테이너:
  * 좌측: 상태 아이콘 (💡 가이드, ⚡ 해석알림, ⚠️ 경고, ✅ 합격) + 진단 메시지 텍스트
  * 우측: 상황별 스마트 액션 버튼 그룹 (예: `[일괄 해석 실행]`, `[KDS 부재설계 이동 →]`, `[단면 최적화]`, `[계산서 출력 →]`)
  * 닫기/최소화 버튼

### 2.2. 프론트엔드 공학 상태 진단 엔진 (`app.js`)
* `updateSmartAssistantState()` 함수 구현 및 주요 이벤트 바인딩:
  1. **단면 수정 감지 (Section Modified)**:
     * 조건: 파라메트릭 치수 변경 또는 DXF 새로 로드
     * 메시지: `"단면 형상이 변경되었습니다. 성질 계산 및 FSM 좌굴해석을 갱신하세요."`
     * 액션: `[⚡ 원클릭 일괄 해석 실행]` (F5 단면성질 + F11 FSM 좌굴 연쇄 실행)
  2. **FSM 좌굴 해석 완료 (FSM Solved)**:
     * 조건: 시그니처 커브 계산 완료 및 극솟점($P_{crl}, P_{crd}$) 확보
     * 메시지: `"국부/왜곡 좌굴 임계하중이 산출되었습니다. 부재설계 검토를 진행하세요."`
     * 액션: `[Step 4 부재설계로 이동 →]`
  3. **부재설계 강도 초과 (D/C > 1.0, NG 발생)**:
     * 조건: 압축/휨/전단/크리플링 중 D/C > 1.0
     * 메시지: `"부재 내력 초과 (최대 D/C = X.XX, NG). 단면 보강 또는 최적화를 권장합니다."`
     * 액션: `[⚡ 퀵 디자인으로 최적 단면 탐색]` 또는 `[두께 1단계 증가]`
  4. **모든 검토 완료 (All Passed, OK)**:
     * 조건: 모든 D/C $\le$ 1.0 만족
     * 메시지: `"모든 KDS 부재설계 검토를 통과했습니다. (최대 D/C = X.XX, OK)"`
     * 액션: `[📄 Step 5 구조계산서 출력 및 PDF 저장 →]`
