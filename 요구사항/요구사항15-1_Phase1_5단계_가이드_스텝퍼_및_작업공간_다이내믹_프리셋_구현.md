## 1. 개요 및 목표

* 상단 헤더 아래에 5단계 엔지니어링 표준 워크플로우를 안내하는 **스텝퍼(Workflow Pipeline Stepper)** 바를 신설합니다.
* 사용자가 현재 진행 중인 단계를 직관적으로 인지하고, 각 단계 클릭 시 해당 작업에 최적화된 **화면 레이아웃 프리셋(Layout Preset 1~5)**으로 화면 구성이 유기적으로 자동 재편되도록 구현합니다.

---

## 2. 세부 개발 항목

### 2.1. 상단 워크플로우 스텝퍼 컴포넌트 마크업 (`index.html`)
* 글로벌 네비게이션 헤더 아래 `#workflowStepper` 컨테이너 추가:
  1. `Step 1. 단면 모델링 (Modeling)`
  2. `Step 2. 단면 성질 (Properties)`
  3. `Step 3. FSM 좌굴해석 (Buckling)`
  4. `Step 4. KDS 부재설계 (Member Design)`
  5. `Step 5. 구조계산서 출력 (Report & Export)`
* 각 스텝 아이템:
  * 스텝 번호 배지 (`1` ~ `5`)
  * 단계 명칭 및 영문 서브텍스트
  * 실시간 공학 상태 인디케이터 배지 (`badge-status`: `ready`, `need-calc`, `pass-ok`, `fail-ng`)
* 스텝퍼 우측:
  * `[← 이전 단계]` 및 `[다음 단계 (Next Step) →]` 전역 네비게이션 버튼 상시 노출

### 2.2. 단계별 다이내믹 레이아웃 프리셋 스타일 (`style.css`)
* 메인 컨테이너에 `data-step="1"` ~ `data-step="5"` 속성 적용에 따른 CSS 그리드/플렉스 자동 전환:
  * **Step 1 (모델링 집중)**: 좌측 파라메트릭 패널(350px) + 중앙 2D CAD 캔버스(Flex 1), 하단 FSM 및 우측 D/C 축소/접힘
  * **Step 2 (단면성질 집중)**: 중앙 2D 캔버스(유효단면 오버레이) + 우측 Gross/Effective 단면성질 대시보드(380px)
  * **Step 3 (좌굴해석 집중)**: 중앙 Three.js 3D 파형 뷰어(50%) + 하단 Chart.js 시그니처 커브(50%) 분할 뷰
  * **Step 4 (부재설계 집중)**: 좌측 부재/크리플링 입력 패널 + 우측 D/C 게이지 및 P-M 상관도 카드
  * **Step 5 (계산서출력 집중)**: 중앙 A4 구조계산서 뷰어 전체화면 + 좌측 목차 아코디언

### 2.3. 스텝퍼 인터랙션 및 상태 제어 엔진 (`app.js`)
* `setWorkflowStep(stepNumber)` 함수 구현:
  * 액티브 스텝 하이라이트 및 CSS 클래스 전환
  * 작업공간 프리셋 전환 애니메이션
  * 캔버스/Three.js/Chart.js 리사이즈(`resize()`, `render()`) 자동 트리거
* 단축키 지원: `Alt+1` ~ `Alt+5`로 스텝 즉시 전환, `Alt+→` / `Alt+←`로 전후 이동
