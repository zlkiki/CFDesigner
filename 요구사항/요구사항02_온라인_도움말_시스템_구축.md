# [요구사항 02] AltDP 스타일 온라인 도움말 시스템 구축 및 한글화/KDS 현대화

## 1. 배경 및 목표
- 레거시 CFS 14.0의 95개 HTML 도움말 자산을 기반으로, **현재 구축된 AltDP 웹 UI/UX(2D CAD 캔버스, Three.js 3D 뷰어, Chart.js 시그니처 커브 등) 및 국내 최신 건설기준(KDS 14 31 10)**에 완벽히 부합하도록 현대화 및 한글화한다.
- 웹 브라우저에서 `/manual` 경로로 접속 가능한 **독립 웹 매뉴얼 뷰어(트리 목차, 키워드 검색, 다크/라이트 테마, 수식 및 SVG 다이어그램 포함)**를 구축하고, 메인 앱 상단 툴바에 **[❓ 온라인 매뉴얼]** 버튼을 연동하여 언제든 즉시 열람할 수 있도록 한다.

---

## 2. 세부 개발 마일스톤 (Milestones)

### 🔹 Milestone 1: 한글화 & KDS 현대화 매뉴얼 콘텐츠 데이터셋 구축
- [ ] 4대 카테고리 15개 핵심 토픽 콘텐츠 생성 (`src/web/manual/content/*.json` 또는 HTML)
  1. **시작하기 & UI 가이드**: 시스템 소개, 4분할 레이아웃, 단면 마법사, DXF 업로드
  2. **단면 기하학적 성질 이론**: Gross 성질, 생브낭 비틀림($J$), 뒴상수($C_w$), 전단중심($S_C$), 주축($I_1, I_2, \theta_p$)
  3. **FSM 탄성 좌굴해석 이론**: 유한대판법 강성행렬, 국부/왜곡/전체 좌굴모드 판별, 시그니처 커브 및 3D 뷰어
  4. **KDS 14 31 10 부재설계**: 직접강도법(DSM) 압축($P_n$), 휨($M_n$), 전단($V_n$), 크리플링($P_{nc}$), P-M 조합식, A4 구조계산서

### 🔹 Milestone 2: AltDP 스타일 반응형 온라인 매뉴얼 뷰어 (`/manual`) 개발
- [ ] `src/web/manual.html`: 모던 문서 뷰어 레이아웃 (좌측 트리 목차 네비게이션, 상단 검색창, 중앙 본문 리더)
- [ ] `src/web/static/css/manual.css`: AltDP 테마 기반 문서 스타일시트 (수식 렌더링, 테이블, 콜아웃 블록, 다크/라이트 모드)
- [ ] `src/web/static/js/manual.js`: 토픽 라우팅, 실시간 키워드 필터링 검색, 콘텐츠 동적 로딩

### 🔹 Milestone 3: FastAPI 백엔드 라우터 및 메인 앱 연동
- [ ] FastAPI 엔드포인트: `GET /manual` (매뉴얼 메인 서빙) 및 `GET /api/manual/topics`, `GET /api/manual/topic/{topic_id}`
- [ ] 메인 앱(`src/web/index.html` & `app.js`): 상단 헤더에 **[❓ 온라인 매뉴얼]** 버튼 추가 및 새 창/모달 연동

### 🔹 Milestone 4: 단위 테스트 및 브라우저 E2E 검증
- [ ] 매뉴얼 API 단위 테스트 (`tests/test_manual_api.py`)
- [ ] 브라우저 서브에이전트를 통한 매뉴얼 뷰어 렌더링, 검색, 목차 클릭, 테마 토글 검증 완료

## 3. 검증 및 수용 기준 (Acceptance Criteria)
- [ ] 메인 앱 상단의 도움말 버튼 클릭 시 `/manual` 페이지가 정상 로드될 것.
- [ ] 좌측 목차 트리에서 토픽 선택 시 해당 한글화 공학 이론 및 UI 가이드가 실시간 렌더링될 것.
- [ ] 상단 검색창에 '좌굴', '전단중심', 'KDS' 등 키워드 입력 시 관련 토픽이 즉시 필터링될 것.
- [ ] 모든 공학 공식과 용어가 KDS 14 31 10 기준 및 국내 표준 구조공학 용어로 표기될 것.
