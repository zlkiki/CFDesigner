## 1. 배경 및 목적
* **배경**: 레거시 CFS 및 AISI 기술 문헌의 온라인 도움말을 한글화 및 KDS 기준으로 현대화하였으나, 공학적 정밀성이 요구되는 전문 용어나 미묘한 뉘앙스에 대해 **번역 오류나 해석 차이가 발생할 수 있다는 우려**가 있음.
* **목표**: 사용자가 한글 설명을 읽는 도중 언제든 손쉽고 직관적으로 **원문(Original English Reference)을 즉시 확인·대조할 수 있는 UI/UX 기능**을 추가하여 정보의 신뢰성과 공학적 무결성을 극대화한다.

---

## 2. 세부 요구사항 및 개발 범위

### 🔹 Milestone 1: 영문 원문 데이터셋 매핑 및 백엔드 확장
- [ ] **1.1 토픽별 영문 원문 데이터(`content_en`, `sections_en`) 구조화**:
  - `src/web/manual/topics.py` 내 각 15개 토픽에 대해 한글 콘텐츠에 대응하는 레거시 원문 영문 텍스트(`content_en`, `title_en`) 데이터셋 보강.
- [ ] **1.2 백엔드 API 응답 모델 확장**:
  - `src/api/manual_routes.py`의 `GET /api/manual/topic/{topic_id}` 응답에 원문 데이터(`content_en`, `sections`) 포함.

---

### 🔹 Milestone 2: 사용성 중심의 영문 원문 대조/토글 UI/UX 구현
- [ ] **2.1 상단 글로벌 뷰 모드 전환 툴바 (3-Way View Switcher)**:
  - 매뉴얼 상단 헤더에 `[🇰🇷 한글만]`, `[🌐 한-영 2열 대조 (Split View)]`, `[🇺🇸 영문 원문만]` 3가지 뷰 모드 토글 버튼 추가.
  - 사용자가 선택한 모드를 `localStorage`에 자동 저장하여 페이지 이동 시에도 상태 유지.
- [ ] **2.2 섹션/단락별 인라인 원문 토글 (Inline Toggle Accordion)**:
  - 한글 뷰 모드에서도 각 주요 공학 설명/수식 블록 우측에 미니 `[🌐 원문보기]` 버튼 배치.
  - 클릭 시 해당 블록 바로 아래에 AltDP 스타일의 은은한 원문 카드(English Callout Block)가 펼쳐지도록 애니메이션 구현.
- [ ] **2.3 전문 용어 툴팁 팝오버 (Term Tooltip & Hover Peek)**:
  - 주요 공학 전문 용어 및 수식 기호에 마우스 호버 시 원문 표현 및 영문 정의를 즉시 보여주는 경량 툴팁 연동.

---

### 🔹 Milestone 3: AltDP 테마 스타일링 및 반응형 지원
- [ ] **3.1 2열 스플릿 뷰(Side-by-Side) 반응형 레이아웃**:
  - 데스크톱 해상도에서는 좌:한글 / 우:영문 5:5 듀얼 패널 뷰 제공 (동기화 스크롤 지원).
  - 모바일/태블릿 화면에서는 상/하 배치로 자동 전환.
- [ ] **3.2 다크/라이트 테마 일관성 유지**:
  - 영문 원문 인라인 카드 및 스플릿 패널의 배경색, 폰트(Monospace/Inter/Pretendard), 테두리를 AltDP 테크니컬 디자인 시스템에 맞게 최적화 (`src/web/static/css/manual.css`).

---

- [ ] **4.2 브라우저 E2E 인터랙션 검증**:

## 3. 검증 및 수용 기준 (Acceptance Criteria)

- [ ] **AC-1**: 토픽 상세 조회 시 한글과 영문 원문 데이터가 모두 정상적으로 반환되어야 한다.
- [ ] **AC-2**: 상단 뷰 모드 전환 버튼 클릭 시 `[한글]`, `[한-영 2열 대조]`, `[영문]`으로 화면 레이아웃이 즉각 전환되어야 한다.
- [ ] **AC-3**: 한글 모드에서도 각 섹션별 `[🌐 원문보기]` 버튼을 클릭하면 원문 박스가 부드럽게 펼쳐지고 접혀야 한다.
- [ ] **AC-4**: 다크 모드와 라이트 모드 모두에서 영문 원문 텍스트의 가독성이 뛰어나야 하며, KaTeX 수식이 깨짐 없이 렌더링되어야 한다.
- [ ] **AC-5**: 모든 기존 단위 테스트 및 신규 원문 API 테스트가 100% 통과하여야 한다.
