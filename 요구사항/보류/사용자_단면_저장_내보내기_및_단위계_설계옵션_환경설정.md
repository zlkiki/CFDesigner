## 1. 배경 및 요구 목적

CFDesigner는 Phase 1~5를 통해 C# CFS.exe의 핵심 공학 알고리즘(기하, FSM, KDS 부재설계, 1D 구조해석, 라이브러리 브라우징, 한·영 도움말)을 성공적으로 웹으로 포팅 완료하였습니다.

그러나 현재 시스템에는 다음 **2가지 실무적 편의 및 레거시 잔여 기능**이 누락되어 있습니다:
1. **사용자 정의 단면의 저장 및 내보내기/불러오기 부재**:
   - 사용자가 마법사나 DXF, 요소 편집기를 통해 생성/변환한 비정형 단면을 프로젝트 파일(JSON)로 내보내거나, 웹 브라우저 로컬 저장소(LocalStorage/IndexedDB)에 영구 저장하여 재사용할 수 있는 기능이 없음.
2. **단위계 및 전역 설계 옵션(Preferences) 제어 부재 (`frmOptions.cs`)**:
   - 단위계 변환 (SI: mm, kN, MPa $\leftrightarrow$ US: in, kip, ksi $\leftrightarrow$ MKS) 지원 필요.
   - 설계법(LRFD 한계상태설계법 $\leftrightarrow$ ASD 허용응력설계법) 전환 및 저항계수($\phi$) 오버라이드.
   - A4 구조계산서 프로젝트 헤더(프로젝트명, 구조물명, 설계자, 검토자, 회사 로고 등) 사용자 맞춤 설정.

## 2. 상세 요구사항 명세

### 2.1 사용자 정의 단면 저장 및 가져오기/내보내기 (User Section Library)
* **내보내기 (Export)**:
  - 현재 작업 공간의 단면(요소 좌표, 두께, 재료 물성치, 하중 조건 등)을 `.json` 포맷의 표준 프로젝트 파일로 원클릭 다운로드.
* **가져오기 (Import)**:
  - 이전에 저장된 CFDesigner `.json` 프로젝트 파일을 드래그&드롭 또는 파일 선택으로 로드하여 단면 형상, 해석 파라미터, 하중 조건 즉시 복원.
* **로컬 사용자 단면 라이브러리 (My Sections / Custom Library)**:
  - 상단 툴바 또는 단면 라이브러리 모달에 **[👤 내 단면]** 탭 추가.
  - 현재 단면을 별칭(Name)과 메모를 지정하여 브라우저 로컬 스토리지에 등록.
  - 내 단면 목록에서 클릭 시 작업 공간으로 즉시 불러오기 및 단면 삭제 기능 제공.

### 2.2 단위계 및 설계 옵션 환경설정 모달 (Preferences Dialog - `frmOptions.cs`)
* **상단 툴바에 [⚙️ 환경설정] 버튼 신설**:
* **1. 단위계 설정 (Unit System)**:
  - **SI 단위계 (기본값)**: 치수 $\text{mm}$, 하중 $\text{kN}$, 응력 $\text{MPa}$, 모멘트 $\text{kN}\cdot\text{m}$, 단위중량 $\text{kg/m}$
  - **US 단위계**: 치수 $\text{in}$, 하중 $\text{kip}$, 응력 $\text{ksi}$, 모멘트 $\text{kip}\cdot\text{ft}$, 단위중량 $\text{lb/ft}$
  - **MKS 단위계**: 치수 $\text{cm}$, 하중 $\text{tonf}$, 응력 $\text{kgf/cm}^2$, 모멘트 $\text{tonf}\cdot\text{m}$
  - 단위계 변경 시 2D 캔버스, 단면 특성치 테이블, FSM 차트, 부재설계 폼의 단위 라벨 및 수치 실시간 자동 변환.
* **2. 설계 규준 및 저항계수 옵션 (Design Preferences)**:
  - 설계 기준 선택: **KDS 14 31 10 (LRFD)** / **AISI S100 LRFD** / **AISI S100 ASD**
  - 저항계수($\phi$) / 안전율($\Omega$) 사용자 커스텀 오버라이드 옵션:
    - 압축 저항계수 $\phi_c$ (기본값: 0.85, ASD $\Omega_c = 1.80$)
    - 휨 저항계수 $\phi_b$ (기본값: 0.90, ASD $\Omega_b = 1.67$)
    - 전단 저항계수 $\phi_v$ (기본값: 0.95, ASD $\Omega_v = 1.60$)
    - 웨브 크리플링 저항계수 $\phi_w$ (기본값: 0.85 ~ 0.90)
* **3. A4 구조계산서 프로젝트 정보 (Report Meta Settings)**:
  - 프로젝트명 (Project Name)
  - 구조물/부재 위치 (Member Mark / Location)
  - 설계자 (Designed by), 검토자 (Checked by), 승인자 (Approved by)
  - 계산서 헤더 일자 및 비고 입력란

## 4. 검증 기준 (Acceptance Criteria)

1. [ ] **단면 JSON 내보내기 & 가져오기**:
   - 임의의 C형강/비정형 단면 생성 후 JSON 다운로드 $\rightarrow$ 페이지 새로고침 $\rightarrow$ JSON 업로드 시 100% 동일한 상태로 복원되는지 검증.
2. [ ] **사용자 정의 단면 브라우저 저장/로드**:
   - `[내 단면 저장]` 클릭 후 라이브러리 모달 `[내 단면]` 탭에서 목록 표시 및 원클릭 로드/삭제가 정상 동작하는지 검증.
3. [ ] **단위계 실시간 변환**:
   - `SI(mm/kN)` $\rightarrow$ `US(in/kip)` 변경 시 단면 치수, 기하 성질($A_g, I_x$), 설계 내력($\phi P_n$)이 정확한 환산 계수($1\text{ in} = 25.4\text{ mm}$, $1\text{ kip} = 4.44822\text{ kN}$)로 표기되는지 검증.
4. [ ] **LRFD $\leftrightarrow$ ASD 설계 모드 전환**:
   - ASD 모드 선택 시 설계강도 $\phi P_n$ 대신 허용강도 $P_n/\Omega$로 표기되고 안전율 기반 D/C 계산이 올바르게 수행되는지 검증.
5. [ ] **A4 계산서 메타데이터 반영**:
   - 환경설정에 입력한 프로젝트명, 설계자 정보가 A4 구조계산서 상단 표제부에 올바르게 인쇄되는지 검증.
6. [ ] **단위 및 통합 테스트**: `pytest tests/` 전수 통과.
