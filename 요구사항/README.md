## 📌 AltDP 표준 요구사항 처리 규약
1. **경량화 원칙**: 사용자가 요청사항 전달 시 별도 Implementation Plan 없이 `요구사항/요구사항XX.md` 생성에 집중 (일련번호는 `@@OLD/` 마지막 번호의 다음 번호 부여).
2. **대규모 요구사항 세분화 (Scope Partitioning)**: 3개 이상 레이어/파일 10개 이상에 걸친 대규모 작업은 누락 위험을 알리고 하위 문서(`요구사항XX-1.md` 등) 또는 독립 Phase로 분할 진행.
3. **전수 체크리스트 검증 의무**: 요구사항 내 수용 기준(Acceptance Criteria)을 1:1 체크리스트로 대조 검증 (누락 0건 확인).
4. **명시적 요청 시 아카이빙**: 개발 완료 후 사용자 명시적 요청 시에만 `요구사항/@@OLD/요구사항XX-YYMMDD_HHMM.md`로 이동 및 아카이빙.
