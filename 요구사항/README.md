## 📌 요구사항 문서 관리 규약
1. **SSOT와의 역할 분리**:
   - `docs/`: 시스템의 변하지 않는 이론, 공식, 아키텍처 기준 (SSOT)
   - `요구사항/`: 개발할 기능의 명세, 구현 단위, 마일스톤, 완료 체크리스트
2. **명명 규칙**: `요구사항XX_[기능명].md` 형식으로 순번 부여
3. **완료 및 아카이빙**: 개발 및 검증이 완료된 요구사항은 체크리스트를 갱신하고, 사용자 요청 시 `@@OLD/` 서브 디렉토리로 아카이빙합니다.
