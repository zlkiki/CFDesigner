## 1. 배경 및 문제 정의 (Issue Summary)

### 1.1 현상
- 웹 UI 상에서 단면을 생성하거나 DXF 업로드, 단면 템플릿 변경 시 하단 글로벌 상태 표시줄에 `FSM 탄성 버클링 해석 실패` 경고가 노출되고, `2D 변형 형상` 토글 버튼을 눌러도 2D 변형 모드가 화면에 나타나지 않는 현상 발생.
- FSM 세부 설정 모달에서 응력분포(휨 모멘트) 수정 시 2, 3차 모드가 미표기되거나, 반파장이 길어질 때 3차 모드 수치가 비정상적으로 폭증하여 차트 스케일이 왜곡되는 현상 발생.
- 단면 도심정렬 시 응력분포 상태가 순수 압축으로 초기화되던 현상 발생.

### 1.2 근본 원인 분석 (Root Cause Analysis)
1. **프론트엔드 렌더링 파이프라인 TypeError 크래시**:
   - `viewer_3d.js`에 `buildStressProfile()` 메서드가 정의되어 있지 않아 호출 시 `TypeError` 발생 $\rightarrow$ 후속 2D 변형 모드 전달 및 라벨 갱신이 스킵되고 `catch` 블록으로 이동하여 `FSM 탄성 버클링 해석 실패` 허위 경고 노출.
2. **세부 설정 엔드포인트 직렬화 누락**:
   - `/api/fsm/parameters`에서 다중 모드 배열(`mode_lfs`, `mode_pcrs`, `mode_mcrs`) 및 3D 절점 변위(`nodes`, `strips`)가 누락되어 2, 3차 모드 곡선 미표기 발생.
3. **휨 상태 고차 비좌굴 모드 수치 발산**:
   - 휨 상태에서 $L > 500\text{ mm}$일 때 면내 막 변형(In-plane Membrane) 고차 고유치가 $O(L^2)$ 형태로 급상승($M_{cr3} \sim 1.7 \times 10^6\text{ kNm}$)하여 Chart.js Y축 스케일을 왜곡시킴.
4. **`load_type` 상태 유실**:
   - `runFSM()`에서 `load_type`을 전달하지 않아 도심정렬 시 `"compression"`으로 리셋됨.

## 2. 세부 조치 및 구현 내역 (Resolved Actions)

### 2.1 3D 뷰어 응력 프로파일 시각화 구현 (`src/web/static/js/viewer_3d.js`)
- `buildStressProfile()` 정식 구현: 단면 시작 위치($z = -110$)에서 절점별 정규화 수직응력 화살표(`THREE.ArrowHelper`) 벡터 메쉬 생성 및 메모리 해제 로직 완비. `TypeError` 원천 차단.

### 2.2 프론트엔드 FSM 렌더링 파이프라인 예외 격리 (`src/web/static/js/app.js`)
- `fsmChart.updateData`, `viewer3d.setData`, `canvas2d.setFsmModeData`, `update3dOverlayInfo`, `수치 라벨 갱신`을 개별 `try-catch`로 격리.
- `this.currentFsmStressType` 상태를 영구 보존하여 도심정렬 후에도 휨 응력 상태 유지.

### 2.3 백엔드 다중 모드 직렬화 및 고차 모드 발산 필터링 (`src/api/routes.py`, `src/solver/signature_curve.py`)
- `/api/fsm/parameters`에서 `mode_lfs`, `mode_pcrs`, `mode_mcrs`, `nodes`, `strips`를 `/api/fsm/solve`와 100% 동일하게 생성·반환.
- $\lambda_k > 25\lambda_1$ 또는 $\lambda > 100,000$인 비물리적 막 발산 모드를 필터링하여 유효한 좌굴 곡선만 반환.

### 2.4 Chart.js 차트 Y축 스케일 보호 (`src/web/static/js/chart_fsm.js`)
- Mode 1 최대값 기준 가시 범위 상한(`upperLimit = maxM1 * 4.0`)을 적용하여 Y축 스케일 폭증을 방어하고, Mode 1, Mode 2, Mode 3의 형상이 선명하게 표시되도록 보장.
