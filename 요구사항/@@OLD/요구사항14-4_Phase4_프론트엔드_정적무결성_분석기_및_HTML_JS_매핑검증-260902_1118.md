## 2. 세부 구현 요구사항

### 2.1 신규 테스트 파일 작성 (`tests/ui/test_frontend_integrity.py`)
1. **HTML DOM ID ↔ JavaScript 바인딩 1:1 교차 검증**:
   - `src/web/templates/index.html` 내의 모든 `id="XYZ"`를 추출.
   - `src/web/static/js/*.js` 파일들에서 참조하는 `document.getElementById('XYZ')`, `$('#XYZ')`, `document.querySelector('#XYZ')` 목록을 추출.
   - JS에서 참조하는 모든 ID가 HTML 내에 실제로 존재하는지 1:1 교차 검증 (ID 오타 및 결측 즉시 감지).

2. **JavaScript 클래스 간 메서드 호출 정합성 검증**:
   - `app.js`에서 타 클래스 인스턴스에 대해 호출하는 메서드 추출:
     - `this.viewer3d.methodName(...)`
     - `this.canvas2d.methodName(...)`
     - `this.fsmChart.methodName(...)`
     - `this.reportGen.methodName(...)`
   - 타겟 클래스 소스 파일(`viewer_3d.js`, `canvas_2d.js`, `chart_fsm.js`, `report.js`) 내에 해당 메서드가 `methodName(...)` 또는 `methodName = function(...)` 형태로 정의되어 있는지 정적 파싱 검증.
   - 예: `viewer_3d.js`의 `buildStressProfile()` 누락과 같은 `TypeError` 버그를 즉각 검출.

3. **정적 자산 및 매뉴얼 도해 링크 무결성 검증**:
   - `index.html` 및 `src/manual/*.json` 내에 기재된 로컬 리소스 경로(`/static/images/manual/*.png`, `/static/css/*.css`, `/static/js/*.js`)가 실제 파일 시스템(`src/web/static/` 등)에 실재하는지 전수 검증.
   - 깨진 링크(404 Broken Assets) 0건 확인.
