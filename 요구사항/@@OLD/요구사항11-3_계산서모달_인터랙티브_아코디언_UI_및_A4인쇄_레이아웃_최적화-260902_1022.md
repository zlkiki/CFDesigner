## 1. 작업 목적
웹 UI 상의 구조계산서 모달(`#reportModal`, `#reportConfigDrawer`) 및 출력 뷰어에 Trace 전용 인터랙티브 UI(부재력별 접기/펼치기 아코디언, 전체 수식 확장 토글)를 탑재하고, A4 브라우저 인쇄 및 PDF 저장 시 수식 박스가 페이지 경계에서 잘리지 않도록 정밀 인쇄 스타일시트를 적용합니다.

---

## 2. 세부 구현 범위
1. **인터랙티브 Trace 아코디언 컴포넌트**:
   - 계산서 모달 내에서 축압축, 강축휨, 약축휨, 전단, 크리플링, P-M 상관식 블록을 독립적으로 열고 닫을 수 있는 UI (`<details class="trace-accordion">` 및 스타일링).
   - "모든 수식 상세 펼치기 / 접기" 원클릭 제어 버튼 제공.
2. **리포트 설정 드로어 연동 (`#reportConfigDrawer`)**:
   - `[x] 상세 계산 과정 (Calculation Trace Details) 포함` 체크박스 연동.
   - 체크 여부에 따라 실시간 리포트 다시 렌더링.
3. **A4 인쇄/PDF 저장 스타일 최적화**:
   - `@media print` 규칙 내에서 아코디언 자동 강제 전개(`open` 상태로 인쇄).
   - `page-break-inside: avoid;` 및 `break-inside: avoid;`를 모든 수식 블록, 테이블 및 다이어그램에 적용하여 수식 중간 잘림 원천 방지.
   - 인쇄 시 여백 15mm 규격 및 헤더/푸터 페이지 번호 표시 최적화.
