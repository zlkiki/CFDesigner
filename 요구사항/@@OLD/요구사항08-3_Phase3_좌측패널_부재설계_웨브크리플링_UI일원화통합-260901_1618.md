## 1. 구현 목표 (1이슈 단일 집중)

* **이슈 내용**: 현재 좌측 제어패널에서 부재력 검토(P-M 조합응력)와 웨브 크리플링 검토가 서로 다른 패널/위치로 분리되어 있어 설계 흐름이 분절되어 있음.
* **목표**: 좌측 부재설계 섹션 내에 **[부재 내력 P-M 검토]**와 **[웨브 크리플링 (Web Crippling) 검토]**를 직관적인 통합 탭/아코디언 일원화 레이아웃으로 통합하고, 소요 하중 입력 및 1D 해석 연동 시 지압력($P_{wc} = V_u$)이 유기적으로 자동 연계되도록 구성.

---

## 2. 세부 개발 명세

1. **좌측 패널 설계 영역 통합 레이아웃 (`index.html`)**:
   - `[🏛️ 부재설계 및 강도검토]` 단일 카드 내에 서브 세그먼트 탭 구성:
     - 탭 1: **`[📊 부재력 P-M 조합검토]`** (비지지길이 $L_x, L_y, L_t, L_b$, 설계하중 $P_u, M_{ux}, M_{uy}, V_u$, 강도 $\phi P_n, \phi M_n$, D/C 게이지)
     - 탭 2: **`[🧱 웨브 크리플링 검토]`** (재하조건 IOF/EOF/ITF/ETF, 지압길이 $N$, 플랜지 부착 여부, 크리플링 강도 $\phi P_n$, 휨-크리플링 조합식 D/C)
2. **소요 하중 및 지점 반력 자동 연계 (`app.js`)**:
   - 전단력 $V_u$ 입력 시 웨브 크리플링 소요 지압력($P_{wc}$) 기본값으로 자동 연동.
   - 1D 구조해석 연동 시 최대 전단력/지점 반력이 웨브 크리플링 소요 하중으로 실시간 전달.
3. **종합 설계 판정 배지 일원화**:
   - D/C 게이지 영역에 압축, 휨, 전단과 함께 웨브 크리플링의 최대 D/C ratio를 통합 집계하여 최악 조건 D/C(Worst D/C)를 메인 판정으로 표시.
