# 요구사항 14-3: [Phase 3] 다단계 사용자 시나리오 상태 전이 E2E 통합 검증

## 1. 목적 및 범위
사용자가 웹 UI 상에서 실제로 수행하는 일련의 연속적인 조작(단면 변경 $\rightarrow$ 하중/응력 수정 $\rightarrow$ 기하 변환 $\rightarrow$ 좌굴해석 $\rightarrow$ 부재설계 $\rightarrow$ 최적화 $\rightarrow$ 계산서 생성) 흐름을 모사하여, 단발성 API 테스트로는 감지할 수 없는 **상태 유실(State Loss) 및 복합 파이프라인 결함**을 원천 차단합니다.

---

## 2. 세부 구현 요구사항

### 2.1 신규 테스트 파일 작성 (`tests/ui/test_stateful_workflows.py`)
1. **시나리오 1: 단면 마법사 $\rightarrow$ 휨 FSM $\rightarrow$ 도심 정렬 $\rightarrow$ KDS 부재설계 $\rightarrow$ 계산서 파이프라인**:
   - Step 1: `/api/section/wizard`로 C150x65x20x2.0 생성.
   - Step 2: `/api/fsm/parameters`로 강축 휨(`bending_x`) 응력 하중 적용 및 해석 실행.
   - Step 3: 도심 정렬 / 회전 변환 API 호출 후, FSM 재해석 시 `load_type="bending_x"`가 리셋되지 않고 유지되는지 검증.
   - Step 4: `/api/design/check`로 휨 모멘트 $M_{ux} = 5.0\text{ kN}\cdot\text{m}$에 대한 KDS 검토 실행.
   - Step 5: `/api/report/html`로 상세 계산서 생성 후 FSM 휨 좌굴 모멘트($M_{crl}$)와 부재 휨강도($\phi M_n$)가 일치 수록되었는지 검증.

2. **시나리오 2: DXF 임포트 $\rightarrow$ 메싱 $\rightarrow$ 리브 삽입 $\rightarrow$ 퀵디자인 최적화**:
   - Step 1: CAD DXF 파일 파싱 및 메싱.
   - Step 2: 립 단부에 추가 리브 삽입 (`/api/geometry/insert-rib`).
   - Step 3: 단면 2차 모멘트($I_x, I_y$) 상승 검증.
   - Step 4: 수정된 단면을 기준으로 `/api/design/quick-design` 최적 부재 탐색 실행.
   - Step 5: 3대 한계상태(강도, 처짐, 웨브크리플링) D/C 산출 정합성 검증.

3. **시나리오 3: SSMA 라이브러리 $\rightarrow$ 냉간가공경화($F_{ya}$) $\rightarrow$ 1D 뼈대 연속보 연동**:
   - Step 1: SSMA 라이브러리(`362S162-43`) 로드.
   - Step 2: 냉간가공경화 공식 적용 ($F_y = 228 \rightarrow F_{ya} = 265\text{ MPa}$).
   - Step 3: `/api/frame1d/analyze`로 2경간 연속보 해석 및 최대 부모멘트/반력 산출.
   - Step 4: 산출된 반력($R_u$)을 웨브 크리플링 지압길이($N = 50\text{ mm}$) 검토에 자동 이양.
   - Step 5: D/C 비율 계산 및 안전 여부 판정 일관성 검증.
