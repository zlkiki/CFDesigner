## 1. 구현 목표

1. **중앙 그래픽 영역의 테마(Light/Dark) 토글 버그를 100% 수정**하여, 테마 변경 시 3D 화면 배경, 2D 원점 원 내부, 도구박스(Toolbar)가 즉시 동기화되도록 조치.
2. **도구상자(마법사, 라이브러리, 변환 도구 등)로 단면이 변경될 때의 반응형 UX 완성**:
   - 2D: 단면 선부터 즉시 변경 $\rightarrow$ 이전 $C_G, S_C$ 삭제 $\rightarrow$ "⏳ 단면 성질 재계산 중..." 플로팅 $\rightarrow$ 완료 후 신규 도심/SC 표시.
   - 3D: 화면 흐리게(블러/Dim) $\rightarrow$ "⏳ 좌굴해석 재계산 중..." 플로팅 $\rightarrow$ 완료 후 신규 3D 좌굴 형상 표시.
3. **상단 불필요한 시스템 안내 메시지 제거**: "중간에 계산을 취소하고..." 알림 제거.
4. **좌측 제어패널의 부재설계(P-M 조합)와 웨브 크리플링(Web Crippling) UI를 단일 일원화 구조로 통합**.

## 2. 세부 개발 명세

### 2.1 3D 좌굴모드 뷰어 테마 연동 (`viewer_3d.js`)
* **Three.js 배경색 동적 전환**:
  - `setTheme(theme)` 메서드 추가: `theme === 'light'`일 때 `scene.background = new THREE.Color(0xf8fafc)`, `dark`일 때 `0x0f172a`.
  - 바닥 그리드(`GridHelper`) 색상: Light 모드 시 밝은 회색(`0xcbd5e1`, `0xe2e8f0`), Dark 모드 시 어두운 색(`0x334155`, `0x1e293b`).
  - 조명(`AmbientLight`, `DirectionalLight`) 밝기 동적 보정.

### 2.2 2D 단면도 캔버스 테마 연동 (`canvas_2d.js`, `style.css`)
* **X-Y 원점 좌표계 원 내부 배경색**:
  - 캔버스 원점 마커 렌더링 시 현재 활성 테마 색상(`getComputedStyle` 또는 `app.theme`)을 참조하여 원 내부 채우기 색상(Light: `#ffffff`, Dark: `#1e293b`) 자동 전환.
* **캔버스 도구박스(Toolbar) 스타일**:
  - `.canvas-toolbar` 배경색 및 테두리를 CSS 변수(`var(--bg-secondary)`, `var(--border-color)`)로 바인딩하여 Light 모드 시 깔끔한 화이트/슬레이트 배경 유지.

### 2.3 단면 변경 시 2D / 3D 반응형 로딩 UX (`canvas_2d.js`, `viewer_3d.js`, `app.js`)
* **2D 캔버스 반응형 워크플로우**:
  1. 단면 요소 변경 시 즉시 단면 중심선/외곽선 렌더링.
  2. 이전 계산 결과인 도심($C_G$) 및 전단중심($S_C$) 마커 즉시 클리어(삭제).
  3. 캔버스 중앙에 반투명 로딩 배지 플로팅: `[⏳ 단면 성질 계산 중...]`
  4. 백엔드 API(`POST /api/section/properties`) 응답 수신 즉시 신규 $C_G, S_C$ 마커 및 주축선 렌더링하고 로딩 배지 해제.
* **3D 뷰어 반응형 워크플로우**:
  1. 단면 변경 즉시 3D 캔버스 영역에 블러 클래스(`filter: blur(2px); opacity: 0.6;`) 적용.
  2. 3D 뷰어 중앙에 플로팅 배지 표시: `[⏳ FSM 좌굴해석 재계산 중...]`
  3. FSM 계산 완료 시 블러 해제 및 신규 3D 모드 형상 애니메이션 적용.
* **상단 배너 메시지 정리**:
  - Debounce 처리나 이전 요청 취소 시 발생하는 "중간에 계산을 취소하고..." 식의 토스트/배너 메시지 노출 완전 제거.

### 2.4 부재설계 & 웨브 크리플링 UI 통합 (`index.html`, `app.js`)
* **좌측 패널 설계 섹션 일원화**:
  - `[부재 내력 검토 (P-M)]`과 `[웨브 크리플링 (Web Crippling)]`을 서브 탭 또는 아코디언 카드 일원화 레이아웃으로 통합.
  - 상단 설계 조건(강종, 부재길이, 하중 $P_u, M_{ux}, M_{uy}, V_u$) 입력 시 웨브 크리플링 소요 지압력($P_{wc} = V_u$) 자동 연계.
  - 종합 안전율(D/C Ratio) 게이지에 축력, 휨, 전단, 크리플링 4대 핵심 지표를 통합 시각화.

## 3. 1:1 수용 기준 (Acceptance Criteria)

- [ ] **AC 1-1**: 우측 상단 테마 토글(Dark $\leftrightarrow$ Light) 클릭 시 3D 좌굴모드 뷰어의 배경색이 즉시 라이트/다크로 전환되는가?
- [ ] **AC 1-2**: 2D 단면도 캔버스의 X-Y 원점 원 및 캔버스 툴바 컨트롤 박스가 라이트 모드에서 검은색으로 남지 않고 정상 전환되는가?
- [ ] **AC 1-3**: 단면 변경 시 2D에서는 이전 도심/SC가 즉시 사라지고 "재계산 중" 플로팅 후 신규 도심이 나타나며, 3D는 화면이 흐려지고 "재계산 중" 배지가 뜨는가?
- [ ] **AC 1-4**: "중간에 계산을 취소하고..."와 같은 불필요한 시스템 안내 메시지가 상단에 노출되지 않는가?
- [ ] **AC 1-5**: 좌측 부재설계 패널 내에서 부재력 검토와 웨브 크리플링이 분리되지 않고 하나의 통합 탭/패널에서 직관적으로 검토되는가?
