## 2. 디렉토리별 수명주기 및 관리 원칙

| 디렉토리 | 수명주기 (Lifecycle) | 관리 및 접근 원칙 |
|---|---|---|
| **`docs/`** | **영구 보존 (Permanent)** | 시스템 아키텍처 및 공학 수식의 **단일 진실 공급원(SSOT)**. 변경 시 실시간 동기화 |
| **`original_source/`** | **영구 보존 (Read-Only)** | 상용 소프트웨어 바이너리 보관소. 절대 수정/삭제 금지 |
| **`decompiled_src/`** | **영구 보존 (Read-Only)** | 역공학된 108개 C# 소스코드 정답 레퍼런스(Ground Truth). 임의 변형 금지 |
| **`scratch/`** | **휘발성 (Volatile)** | 언제든 전체 삭제될 수 있는 임시 테스트 공간. 보존 자산 배치 금지 |
| **`요구사항/`** | **단계적 완료** | 작업 완료 시 `요구사항/@@OLD/`로 아카이빙 관리 |
| **`src/`** | **영구 보존 (신규 개발)** | Python 기반의 독자적인 모던 CAD 연동 해석/설계 패키지 |

## 3. 세부 파일 인벤토리 명세

### 3.1. 원본 바이너리 파일 (`original_source/` - 12개)
* **`CFS.exe`**: 메인 .NET 어셈블리 실행 파일 (v14.0.0.0, 1.9MB)
* **`CFS.chm`**: 공식 도움말 및 이론 매뉴얼 파일 (381KB)
* **`FlexCell.dll`**: 그리드 UI 컨트롤 라이브러리
* **`PLUSManaged.dll`**: Concept Software(SoftwareKey) 라이선스/활성화 보안 모듈
* **단면 라이브러리 (`*.cfsl`)**: `AISI.cfsl`, `LGSI.cfsl`, `SFIA.cfsl`, `SSMA.cfsl`, `HUD.cfsl` (냉간성형강 표준 단면 DB)
* **재료 라이브러리 (`*.mtl`)**: `CFS14.mtl` (ASTM/기본 강재 재료 물성치 DB)
* **`Uninstall.exe`, `Uninstall.ini`**: 프로그램 제거 유틸리티
