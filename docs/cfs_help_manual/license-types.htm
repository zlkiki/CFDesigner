License Types

The CFS software is available to use under three license types: Free License (light mode), Single User License, and Network License.

Free License

After accepting the license agreement and installing the software, CFS will initially use the free license. This license allows you to use the software in "light mode". There are limitations on features and functionality available to you when using the free license. You may purchase a single user license or a network license at any time to upgrade the software to a full license with all the features and functionality enabled.

Single User License

The single user license provides the full functionality of the CFS software. This is an annual subscription which is activated on a specific machine for a specific user. This type of license cannot be used with remote desktop access (terminal services). See Single User License for more information.

Network License

The network license provides the full functionality of the CFS software. This is an annual subscription which allows sharing a license over your network. See Network License for more information.

CFS Automation Module

Both the Single User License and the Network License are available to purchase with the optional CFS Automation Module. These license types enable use of the CFS module for automating CFS calculations in your own software or spreadsheets.

License Purchase

To purchase a license, visit the RSG Software website or go directly to the product catalog on the License Portal.

License Renewal

Your annual license subscription will renew automatically using the credit card information associated with the license. You will receive a notification prior to this automatic payment. Make sure your license information is up to date, otherwise your license may not get renewed. If you are using a legacy Standalone license which is about to expire, you must purchase a new Single User License instead of a renewal.
